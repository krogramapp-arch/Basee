# KroXray

مشروع Android مستقل لإدارة ملفات اتصال Xray محلياً. الواجهة الحالية تدعم استيراد إعداد JSON وروابط VLESS وVMess وTrojan وShadowsocks وSOCKS، وتخزينها واختيار ملف وحذفه.

## الحالة الحالية

- التطبيق لا يحتوي بعد على محرك Xray أو خدمة VPN؛ زر الاتصال يوضح ذلك ولا يبدأ نفقاً وهمياً.
- لا يوجد خادم اشتراكات مرتبط بالمشروع. لا تُرسل ملفات الاتصال إلى أي جهة.
- لم تُنسخ المكتبات الأصلية إلى التطبيق؛ يلزم التحقق من مصدرها وترخيص إعادة توزيعها، ثم توثيق واجهة Go وربط طبقة TUN قبل تفعيل الاتصال.
- الحزمة `com.kroxray` جديدة، ولذلك لا يمكنها ترقية تطبيق «مفتاح» أو الوصول إلى بياناته الخاصة تلقائياً.

## البناء

افتح مجلد `kroxray` في Android Studio مع تثبيت Android SDK 35 وJDK 17 أو أحدث. بعد قبول تراخيص Android SDK محلياً، يمكن بناء نسخة Debug من Android Studio أو بتنفيذ `gradle :app:assembleDebug`.

هذا المجلد لا يضم Android SDK أو Gradle Wrapper.
